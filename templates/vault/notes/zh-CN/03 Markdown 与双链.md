# Markdown 与双链

Agentero 的笔记就是普通 Markdown 文件。你可以在应用内编辑，也可以用任何外部编辑器打开。

## 基础 Markdown

```markdown
# 一级标题

## 二级标题

- 项目符号
- 另一个项目

1. 编号列表
2. 编号列表

**粗体**，*斜体*，`行内代码`
```

```rust
// 代码块
// 点击右上角按钮切换语言类型, 或者复制代码块内容
```

> [!NOTE]
> 支持 Obsidian 风格的 Callout。

Callout 会渲染为带图标和主题色的块。点击标题或左侧图标可就地编辑类型和标题。支持的类型包括 `note`、`tip`、`info`、`warning`、`danger`、`success`、`question`、`quote`、`example` 和 `failure`。

## 公式

行内公式：`$E=mc^2$`

块级公式：

```markdown
$$\int_a^b f(x) dx$$
```

> [!TIP]
> 输入 `\$a\$` 会保持为普通文本；`$a$` 会渲染为公式。

## Slash 命令

在编辑器中输入 `/` 打开轻量命令菜单。用方向键选择、`Enter` 插入。命令包括标题、列表、待办、引用、代码块、图表、链接和 Callout。

常用命令：

| 命令           | 插入                                 |
| -------------- | ------------------------------------ |
| `/mermaid`     | 实时渲染的 Mermaid 图表              |
| `/code`        | 代码块（从语言选择器选语言）         |
| `/callout`     | Obsidian Callout（默认 `note` 类型） |
| `/link`        | 内部双链 `[[]]`                      |
| `/heading 1–3` | 标题块                               |

> [!NOTE]
> `/` 必须位于行首或紧跟空格。在代码块内或双链补全菜单打开时不触发。

## 外部链接

编辑器支持标准 Markdown 外链：

```markdown
[Agentero 官网](https://example.com)
```

手写完整的 `[文字](链接)`（打完最后的 `)` 会变成链接）、直接粘贴同格式，或用右键 / Slash 的 **新增外部链接**（会插入带占位文字的链接节点并打开编辑气泡，填写显示文字与地址）均可。单击已有链接可再编辑；**⌘/Ctrl+单击**、中键或右键用系统浏览器打开。指向 Vault 内其它笔记的相对路径仍走应用内跳转。

## Mermaid 图表

用 `/mermaid` 插入，或在代码块的语言选择器中选择 **Mermaid**。图表预览会显示在源码下方：

```mermaid
graph LR
    A[论文] --> B[阅读]
    B --> C[笔记]
    C --> D[下一步]
```

> [!TIP]
> Mermaid 图表是只读预览 —— 修改上方源码即可更新图表。

## 双链

双方括号既可以链接 Markdown 笔记，也可以链接 PDF。目标格式不同，`#` 的含义也不同：

| 目标 | `#` 规则 | 示例 |
|---|---|---|
| Markdown 笔记 | 按标题文字定位；可用多个 `#` 表示嵌套标题 | `[[笔记.md#实验设置#数据集]]` |
| PDF | 按章节编号定位 | `[[论文.pdf#2.1]]` |
| PDF 段落 | 章节编号后加 `#pN`，定位该章节的第 N 个正文块 | `[[论文.pdf#2.1#p3]]` |

### Markdown 笔记

笔记的 `.md` 扩展名可省略；同名目标有歧义时，写出扩展名或 Vault 相对路径：

```markdown
[[01 论文导入与管理]]
[[01 论文导入与管理.md#论文库（Library）]]
[[01 论文导入与管理#导入方式#Zotero Connector 插件]]
```

输入 `[[笔记#` 搜索标题，再输入 `#` 继续选择子标题。嵌套标题可写完整路径，也可省略开头的祖先，但剩余的连续标题路径必须唯一。

### PDF 章节与段落

PDF 目标保留 `.pdf` 扩展名。`#2`、`#2.1` 是章节编号，`#2.1#p3` 是第 2.1 节的第 3 个正文块，`p3` 不是第 3 页：

```markdown
[[papers/demo/demo.pdf#2]]
[[papers/demo/demo.pdf#2.1]]
[[papers/demo/demo.pdf#2.1#p3|支持这一结论的段落]]
```

输入 `[[论文.pdf#` 后，候选来自 PDF 版面解析中的编号章节，可按章节名搜索。选中章节后，**Enter** 确认章节链接；**Tab** 补成 `论文.pdf#2.1#`，继续选择该章节的段落。段落候选会显示原文，便于核对位置。

PDF 需已有版面解析结果。段落编号按直接所属章节计数，子章节单独计数；一个正文块可能不同于自然段，优先从候选中选择。缺少解析、目标不存在或有歧义时会提示失败。旧式 `[[论文.pdf#section=2.1]]` 与 `[[论文.pdf#page=3]]` 仍兼容；普通 Markdown 链接也可使用相同的 PDF fragment：

```markdown
[第 2.1 节第 3 段](papers/demo/demo.pdf#2.1#p3)
```

### 批注与显示名

用 `@` 链接 PDF 划词 / 视觉批注（`id` 可从批注面板复制，或输入 `[[@` 补全）：

```markdown
[[@批注id]]
[[papers/…/NOTES@批注id|论文标题]]
```

- `#`：Markdown 标题或 PDF 章节/段落；`^`：Markdown 文本块；`|`：显示名；`@`：批注。
- 批注 target 用路径（`NOTES` / `paper.pdf` / `papers/…/NOTES`），不要只用论文展示标题。

双链索引用于内部跳转和反向链接；References 中的文献引用图使用论文参考文献数据，与 Markdown 双链分开。

## 嵌入

在双链前加 `!` 即可嵌入内容：

```markdown
![[01 论文导入与管理#论文库（Library）]]
![[papers/demo/demo.pdf#2.1#p3]]
![[papers/…/NOTES@批注id]]
```

可以嵌入：

- **笔记区段** — `![[笔记#标题#子标题]]`
- **图片** — `![[示意图.png]]` 或 `![](./assets/示意图.png)`
- **整份 PDF** — `![[论文.pdf]]`
- **PDF 章节 / 段落** — `![[论文.pdf#2.1]]` / `![[论文.pdf#2.1#p3]]`
- **PDF 批注预览** — `![[…@批注id]]`

PDF 章节 / 段落嵌入会按容器页宽显示，自动定位并持续浅色高亮目标块；章节高亮标题块，段落高亮对应正文块。滚动离开后，可点顶栏「打开」左侧的 **回到引用位置** 图标。

Markdown 区段和批注预览是只读的，修改内容需打开源文件。**论文主 PDF 的嵌入可直接高亮、编辑备注、改色、删除或添加视觉批注**，与主阅读器共用原论文的 `marks/`；同窗口的多个查看器会同步变更。嵌入内的备注卡片在悬停或编辑时显示在页内。普通附件 PDF 保持基础阅读模式，不使用主论文的批注数据。

## 图片

在 Markdown 笔记中粘贴图片，Agentero 会自动把它存到该笔记的 `assets/` 文件夹：

```markdown
![示意图](./assets/diagram.png)
```

如果图片不再被引用，会被自动清理。
